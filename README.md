# Contact Manager App

A responsive web application for managing contacts, built using HTML, CSS, and JavaScript. It allows users to add, search, edit, and delete contacts, with contact data stored persistently using Browser Local Storage.

## Features

- Add new contacts
- Search contacts
- Edit contact details
- Delete contacts
- Persistent data storage using Local Storage
- Responsive and user-friendly interface

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage

## Project Overview

The Contact Manager App provides a simple and efficient interface for managing contact information. Users can perform basic CRUD operations on contacts, while Local Storage ensures that saved contact data remains available after refreshing the browser.
